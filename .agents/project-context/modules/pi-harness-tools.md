Esc while the orchestrator is idle is not seen by extensions; use `/subagent-cancel`. Verified by unit tests only, not in a live Pi session.

- Team messaging (2026-10-30, user decided: orchestrator-led team, cheap, everything parallel; subagents used for work on this are Haiku 5.5, `claude-bridge/claude-haiku-5-5`): hub with a mailbox, not group chat. `task` takes `name` and `talksTo`; only a named worker gets `message_team` (no prompt cost for the rest).
